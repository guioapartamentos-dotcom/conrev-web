# CONREV Design System

## Objetivo

Construir una identidad visual sólida, moderna y profesional que transmita confianza, organización y cercanía.

---

# Personalidad de la marca

CONREV debe transmitir:

- Confianza
- Transparencia
- Organización
- Profesionalismo
- Cercanía
- Tecnología
- Cumplimiento

Nunca debe verse:

- Recargada
- Infantil
- Exageradamente colorida
- Antigua
- Informal
